만봉프린트 인쇄풍선 시안 제작 사이트
=================================

배포 방법
1. ZIP 압축을 풉니다.
2. index.html과 assets 폴더가 같은 위치에 있는지 확인합니다.
3. Cloudflare Pages에 배포할 때 프로젝트 폴더 전체를 업로드하거나 GitHub 저장소에 전체 파일을 올립니다.
4. index.html만 단독으로 올리면 풍선 이미지가 표시되지 않습니다.

풍선 이미지
- 스탠다드 14종
- 파스텔·마카롱 16종
- 펄·크롬 32종
총 62종의 투명 배경 PNG입니다.

참고
- 기존 로고 업로드, 텍스트/아이콘 편집, 앞면/뒷면, 잉크 색상, 통합 시안 다운로드 기능은 기존 코드 기반으로 유지했습니다.
- 통합 시안의 풍선 사진은 브라우저 미리보기와 동일한 PNG 파일을 사용합니다.
- 고객 접수 및 이메일 전송 기능은 기존 코드와 동일하게 별도 서비스 연결이 필요합니다.
